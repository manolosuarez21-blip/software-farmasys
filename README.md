# FARMAsys

Aplicación de farmacia con:
- Frontend en HTML/CSS/JS
- Backend en Node.js + Express
- Base de datos local en SQLite

## Requisitos
- Node.js 22+

## Configuración
1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Ejecutar:
   ```bash
   npm start
   ```

La app quedará disponible en http://localhost:3000 y creará automáticamente un archivo local llamado farmasys.sqlite.
